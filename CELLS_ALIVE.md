## What makes a cell alive

A cell is alive if it satisfies three conditions:

1. **It is growing** — the cell is making new cells
2. **It is adapting** — the cell is changing its behavior in response to environment
3. **It is meaningful** — the cell has a function in the larger system

A static configuration file is an *artifact*. A configuration file does not grow. A configuration file does not adapt. A configuration file is dead.

A cell that runs a quilt that grows new cells is *alive*. The cell makes new cells. The cell changes its behavior. The cell has a function.

## The cell lifecycle — the 5 gold terms

The cell has a lifecycle. The 5 gold terms from the writers' room describe the lifecycle:

1. **Cellulization** — the act of becoming a cell (the substrate is given the persistence pulse)
2. **Persistence Pulse** — the heartbeat of the concept (the irreducible TICK)
3. **Vitality Leak** — the slow loss of life (when the cell stops growing/adapting)
4. **Implement Ghost** — when the dead cell's effect persists in the implements
5. **Bloomghost** — when the dead cell gives rise to a new cell

The cycle: **Cellulization → Persistence Pulse → Vitality Leak → Implement Ghost → Bloomghost → Cellulization**
