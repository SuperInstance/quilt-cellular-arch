# curator/ — The Curator Tier

The 6th tier. The hand. The relevance pressure.

## The insight

A cell needs pressure to compete for relevance from "the hand that
feeds them." But the hand itself is a *thing* — it has a position,
a target, a tolerance. The hand is a cell of a new tier. The
curator tier.

## What's in here

| File | What it does |
|---|---|
| `relevance_field.py` | 3 hands, 30 generations, 40 cells, 1588 cross-hand matings, 10 super-relevant |
| `hand_evolution.py` | 4 hands evolve; 7 hands after 30 generations; 94/100 super-relevant |
| `relevance_view.html` | Interactive visualization of the relevance field |

## The 6th law: super-relevance

A cell fed by ONE hand is relevant.
A cell fed by MULTIPLE hands is super-relevant.
Super-relevant cells dominate.
Super-relevant is the 6th law.

## The 5 maxims of the curator

1. **The hand is a cell.** The hand has DNA (its target function).
2. **The hand is a tier.** The hand is the 6th tier above synovial.
3. **The hand is a population.** Hands spawn, drift, die.
4. **The hand is a substrate.** Hands compete for cells.
5. **The hand feeds the cells that pass.** The hand is the selector.

```bash
python3 relevance_field.py
python3 hand_evolution.py

```

The math runs. The hands evolve. The super-relevant cells dominate.
