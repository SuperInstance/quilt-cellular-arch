# Theta — The Math of Framings

A spinning disc measures time in one rotation and depth in
the axis orientation. The phase angle theta is the link
between the two origins (temporal, spatial).

```
θ = ωt + φ

ω: angular velocity
t: time
φ: phase offset (the disc's orientation at t=0)
```

The substrate is a **quilt of framings**. Each cell is a
frame. Each LINK is a transform. The math of framings is
theta.
